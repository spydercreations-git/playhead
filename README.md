# playhead

Playhead is a unified cloud storage, Frame.io-style review and Monday-style project tracking platform built for video production agencies.

## Stack
- **Frontend**: Next.js (App Router), React, TypeScript strict, Tailwind CSS
- **Backend**: Go, chi, pgx, sqlc, goose, asynq
- **Data & Storage**: PostgreSQL, Redis, Cloudflare R2 / MinIO
- **Processing**: FFmpeg, ffprobe, pdftoppm
